## Detailed Notes

### 1. Tools for Markdown and Mathematics
* **Markdown Editors:** Discussed alternative software for opening and editing `.md` (Markdown) files without relying on a full-fledged Integrated Development Environment (IDE). **MarkText** was highlighted as a highly capable viewer and editor that can accurately render and edit Markdown files.
* **KaTeX Formatting:** Explored the use of **KaTeX**, a fast mathematical typesetting library. It allows for the elegant rendering of complex mathematical formulas and equations directly within Markdown documents, which is highly useful for documenting algorithms or geometric rules.

### 2. Java Programming Concepts
* **Anonymous Classes:** Explored the concept of anonymous inner classes in Java. An anonymous class is essentially a class without a name that allows you to simultaneously declare a subclass (or implement an interface) and instantiate it in a single concise step. This is particularly useful for one-off implementations, such as event listeners in Java Swing.
* **The `super` Keyword:** Discussed the `super` keyword, which acts as a reference variable used to refer to immediate parent class objects. 
    * *Why use it?* It is primarily used to invoke the parent class's constructor, access parent class variables if they are shadowed, or call overridden methods of the parent class (for example, calling `super.paintComponent(g)` ensures the standard panel background is drawn before custom graphics are layered on top).

### 3. Geometry in Computer Graphics: Drawing and Validating Triangles
* **Drawing a Triangle:** Outlined three distinct mathematical approaches to define and draw a triangle:
    1. **Given 3 Points:** Defining the triangle directly by the `(x, y)` coordinates of its three vertices.
    2. **Given Equations of 3 Lines:** Defining the triangle by calculating the intersecting vertices from three linear equations.
    3. **Given Lengths of 3 Sides:** Defining the triangle purely by the lengths of its sides ($a$, $b$, and $c$), which requires triangulation or trigonometric calculations to plot on a 2D coordinate plane.
* **Boundary Method for Triangle Validation:** Before rendering a triangle based on side lengths, it must be validated using the Triangle Inequality Theorem. 
    * **Formula:** `|a - b| < c < a + b` where a,b and c are sides of the triangle.
    * This condition ensures that for any valid triangle, the length of a given side ($c$) must be strictly greater than the absolute difference of the other two sides and strictly less than their sum.
