## Detailed Notes

### 1. 2D Rendering Basics: Triangles and Interactivity in JavaFX
* **Rendering a Triangle:** A triangle can be easily drawn if you have three distinct, non-collinear (x, y) coordinates. Instead of calculating line intersections, you simply draw line segments connecting the three points in sequence. In JavaFX, the `GraphicsContext.strokePolygon` or `fillPolygon` methods can accomplish this effortlessly.
* **Validating Triangles:** To ensure the three points don't form a flat line, you can use an area formula based on their coordinates. If the calculated area evaluates to zero, the points are collinear and do not form a valid triangle.
* **Interactive Canvas Drawing:** We explored how to draw shapes using mouse events on a JavaFX `Canvas`. By listening for a secondary mouse button click (typically a right-click), we can retrieve the cursor's exact coordinates. To draw a circle centered precisely at the click location, you must subtract the circle's radius from the mouse's `x` and `y` coordinates before rendering the oval.
* **Separating Data from View:** For interactive applications, it is best practice to store drawn shapes in a data model (such as a List of objects holding position and size) rather than just leaving them as static pixels on the canvas. Maintaining a model allows the application to efficiently redraw, move, or interact with the shapes later.

### 2. Geometric Calculations: Connecting and Intersecting Shapes
* **Point-in-Circle Collision Detection:** To check if a user clicked inside a circle, calculate the squared distance between the click coordinates and the circle's center. If this squared distance is less than or equal to the square of the radius, the point is safely inside. Using squared distances is a common optimization that avoids the computational cost of calculating a square root.
* **Drawing Connecting Arrows:** When connecting two circular nodes with an arrow, the line shouldn't start or end at the exact centers, as this causes the line to overlap the shapes. Instead, you can calculate a unit direction vector based on the distance between the two centers and scale it by the circles' radii. This math ensures the arrow's start and end points rest perfectly on the boundaries of the circles.

### 3. Data Structures: Trees and Binary Search Trees
* **Tree Foundations:** A tree is an acyclic, hierarchical data structure that starts from a single root node and branches downwards into child nodes. Important concepts include the *root* (topmost node), *leaf* (a node without children), and *depth/height* (metrics that measure the vertical distance of the hierarchy).
* **Binary Trees vs. BSTs:** 
    * A **Binary Tree** restricts nodes to having a maximum of two children (a left and a right child).
    * A **Binary Search Tree (BST)** introduces a strict ordering rule: left-side children must contain values smaller than their parent, and right-side children must contain larger values. This specific ordering allows for highly efficient search, insertion, and deletion operations—typically running in O(log n) time, provided the tree remains reasonably balanced. If the tree becomes highly unbalanced, these operations can degrade to O(n).
